# FPGA-Shield-Arduino-Compatible
`IT`
Un modulo compatto e facile da usare per esplorare il mondo delle FPGA con la semplicità di Arduino.  
Progettato per integrarsi facilmente con le schede Arduino, questo shield semplifica il caricamento del bitstream e offre un punto di partenza accessibile per sviluppatori.

`EN` 
A compact and user-friendly module for exploring the world of FPGAs with the simplicity of Arduino.  
Designed to integrate seamlessly with Arduino boards, this shield simplifies bitstream loading and provides an accessible starting point for developers.
