# FPGA-Shield-Arduino-Compatible
`IT`
Un modulo compatto e facile da usare per esplorare il mondo delle FPGA con la semplicità di Arduino.  
Progettato per integrarsi facilmente con la schede Arduino R4, questa shield semplifica il caricamento del bitstream e offre un punto di partenza accessibile per sviluppatori.

`EN` 
A compact and user-friendly module for exploring the world of FPGAs with the simplicity of Arduino.
Designed to integrate easily with Arduino R4 boards, this shield simplifies bitstream loading and provides an accessible starting point for developers.

![image](https://github.com/user-attachments/assets/ca62c845-772c-4b98-bee7-0aa1601cdc28)


## Caratteristiche principali / Main Features

`IT` 
- Compatibile con Arduino R4 come shield
- Utilizzabile come modulo indipendente grazie alla memoria on-board
- Caricamento semplificato di bitstream e file binari
- Documentazione disponibile:  
  - Guida rapida in italiano [Quick-start-guide ITALIAN](documents/Quick-start-GR01.pdf) 
  - Diagramma a blocchi [BlockDiagram.pdf](documents/BlockDiagram.pdf)

`EN`  
- Compatible with Arduino R4 as a shield  
- Can be used as a standalone module thanks to onboard memory
- Simplified loading of bitstream and binary files
- Documentation available:  
  - Quick-start guide [Quick-start-guide ENGLISH](documents/Quick-start-GR01EN.pdf)  
  - Block diagram [BlockDiagram.pdf](documents/BlockDiagram.pdf)
